# Project Atlas

Project Atlas 是一个长期投资研究系统，目标是建立持续 10 年的《中国工业冠军研究库》。

Atlas 的核心研究路径：

    人类根本约束
            ↓
    价值流
            ↓
    价值节点
            ↓
    企业
            ↓
    投资组合

核心原则：

- Bear First：先寻找反证；
- Evidence First：证据优先于逻辑；
- Value Flow First：先研究价值流，再研究公司；
- Long-term First：优先研究 5-10 年周期的结构性变化。
